models.json contains the seven GPT model IDs already used by this project's seed policy.
It is normalized to 52 ordered top-level fields and 13 ordered model_messages fields,
covering the official serialized contract and published catalog extension fields.
Missing optional fields use null, collections use arrays, and booleans use the
contract defaults. Legacy shell_command/default/local spellings serialize as unified_exec.
Model-specific instructions, reasoning choices and tool capabilities are retained.
The older three-model Sub2API export has been replaced, not kept as a second source.

Deployment override requested by the user: Astra and Sol family context_window = 500000.
This is a local policy, not a claim that the official tag's default is 500k.
The official max_context_window = 872000 is retained for these models.
The override applies on seed, policy reads, save, sync and catalog export.
These metadata references never add models to a Key's authorized catalog.
Gateway visibility/identity rules and use_responses_lite=false remain enforced on export.
