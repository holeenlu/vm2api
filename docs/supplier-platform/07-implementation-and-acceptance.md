## 本轮新增/更新的验收用例

| 用例 | 操作 | 预期结果 | 证据 |
| --- | --- | --- | --- |
| 身份窃用 | 一级开户传无关用户/超管 user_id | 403，原角色/成员不变，无子级半成品 | S01 / HTTP S11 |
| 空范围与旧数据 | 子级传空 groups/platforms；旧子级空字段 | 继承并受父级当前范围限制，不能开户到未允许平台/分组 | S02/S06 |
| 满额重试/并发 | 同 key 同业务输入重试/并发，及同 key 改内容 | 同一子级与登录账号；冲突为 409 | S03 / HTTP S11 |
| 撤权 | 读身份后撤销成员、create_child 或付款能力 | 下一次写入/聚合/付款被拒绝，无越域数据 | S04/S09 |
| 账号与 VM | 从任一资源暂停、恢复、归档 | 两条资源状态一致；手动停调和凭据保护保持；归档不能授权/启动 | S05 / HTTP S12 |
| 陈旧 VM | 保留 schedulable=true 后停用供应商/撤销范围 | Claude/Codex 选号拒绝，面板不误显可用 | S05/S06 + 调度套件 |
| 开户重放 | 原 key 携带另一代理重试 | 返回原资源，无重新绑定或启动 | HTTP S12 |
| 无效代理更新 | status 无效 | 400，供应商表和统一代理池都不改变 | HTTP S12 |
| 授权终端 | 普通 shell 票据、过期权限票据、正常登录票据 | 供应商只执行固定 auth login；撤权拒绝连接/输入，保持单次票据 | slot-shell-rc + HTTP S12 |
| 统计真实性 | 只有累计 Token、原始错误、Unix 秒 | TPM 未知，不透传原始错误；秒/毫秒/ISO 显示一致 | S07 + portal-model |
| 预览变动 | 同金额但 Token/账号明细改变 | 旧 preview_token 拒绝，需重新预览 | S08 |
| 结算重试 | 生成后合同变化，重复生成/确认 | 返回原账单，不重计金额、不重复写流水 | S08 |
| 下游付款 | 无 pay 能力、有能力、子级、其他付款方 | 显式授权的一级仅能处理自己付款边，二级和跨边拒绝 | S09 / HTTP S11 |
| 分次/重复付款 | 同键重复、改金额、超付、并发同键 | 一条流水；冲突/超付拒绝；双方账单状态一致 | vendor-admin + HTTP S11 |
| 金额/历史保护 | 非有限/超安全精度金额、归档主体恢复 | 业务拒绝，不覆盖旧账或归档状态 | S10 |
| 运营代理池 | 超管按供应商筛选代理，编辑地址/认证，批量检测，启停、归档和查看绑定席位 | 与 `vendor_resources`、统一 `proxy-pool` 同步；凭据不回显；无效状态不改变池；绑定中的代理不能归档 | vendor-admin HTTP 代理工作台用例 |

- 前端：`web/src/features/vendor/portal-model.test.ts`、导航和 i18n 现有测试、TypeScript、相关 lint/格式；新增共享组件后检查生产打包及一次定向 UI。
- 真实环境：实际 OAuth/CLI、guest/KVM、网络代理质量和生产数据对账须有独立运行记录；不把替身或本机截图视为生产验收。

每项以当前代码和输入的实际结果为准；未实现的需求不写空测试或 skip 测试充当覆盖率。无迁移变化不重跑数据库升级矩阵；支付/数据库处置和生产部署不由测试授权推导。

## 待实施验收清单

分组单价应覆盖优先级和生效时间、两条付款边独立快照；迟到费用应覆盖补单和不重复计费；冲正应引用原支付并保证幂等及双方金额一致。导出须覆盖字段过滤、下载权限和历史快照；代理检测须覆盖绑定范围和凭据脱敏；异步任务须覆盖停用、成员移除、归档后旧 claim 不回写。MFA/step-up 必须绑定操作者、动作、对象和有效期。其中070已覆盖门户下游迟到补单、去重分配和平台价格冻结；其他条目仍为后续完成标准。
