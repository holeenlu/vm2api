## RPM 与专属设置

| 设置 | 计数范围 | 0 / 留空 |
| --- | --- | --- |
| 用户 RPM | 该用户全部 Key、全部分组 | 0 = 不限制用户层 |
| 分组 RPM | 每个用户分别计数，同用户在该组的 Key 共享 | 0 = 不限制分组层 |
| 用户专属分组 RPM | 替代此用户在此组的默认 RPM | 0 = 不限制分组层；null = 继承 |
| Key RPM | 此 Key；同时仍检查前两层 | 0 = 不限制 Key 层 |

最近 60 秒已准入请求计数，任一适用上限达到即拒绝。用户 100、分组 A 60、Key 20 时，该 Key 最多 20；多个 Key 在 A 合计最多 60；跨分组合计最多 100。并发、余额与金额窗口仍独立。5 小时、24 小时、7 天为 USD 消费窗口，非请求次数。

专属倍率、RPM 使用同一用户/分组设置表，权限仍由授权或套餐决定。正向迁移 043 将旧授权记录上的倍率保留到新表（包含免费倍率 0），再移除旧重复字段；历史迁移未改写。恢复某项默认不会清除另一项专属设置。

## sub2api 的使用密钥功能移植范围

对照本机定制 sub2api `KeysView.vue`、`UseKeyModal.vue`，按 tapmodels 实际平台复用已有 Key 生命周期：

| 功能 | tapmodels 实现 |
| --- | --- |
| 复制/查看 | 行内复制；单独取回、审计，不在列表或日志回显明文 |
| 使用密钥 | Claude Code、Codex、适用的 Codex WebSocket、OpenCode、API 示例；按密钥可用模型生成 |
| 系统配置 | macOS/Linux、PowerShell、CMD；配置复制和下载，地址保留部署前缀 |
| 创建/编辑 | 搜索用户与可授权分组、自定义密钥、消费与 RPM 限制、IP 规则、有效期快捷值 |
| 生命周期 | 原启停、轮换、撤销、自限额重置、用量查看继续复用；不另建密钥存储 |
| 平台适配 | 不引入 tapmodels 未实现的 Gemini/Grok 等平台、sub2api 专属目录路由或旧认证兼容层 |

Codex 参数核对 [官方配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。使用 `env_key`、`wire_api = "responses"`，生成的配置仅用于展示/下载，不自动改写用户电脑配置或调用供应商推理。

当前 Docker 启动脚本曾在没有显式 DB secret 时重建随机密钥，导致历史密文不可解密。现在自动生成值持久存于数据目录 `runtime-secrets.json`（0600）；`.env` 现存值和显式环境变量可沿用。部署前保存运行进程实际密钥，避免只复制 `docker inspect` 的环境而漏掉入口脚本生成的值。新建/轮换 Key 保持可恢复密文；原 Key 成功哈希认证时可补回密文。无法解密与仅存哈希分别提示，绝不自动轮换历史 Key。

验收反馈同步收口：新分组默认不勾选专属（前后端一致，已有分组保持原设置）；创建/编辑 Key 默认聚焦名称；用户表移除重复分组授权弹窗及其状态、取数、保存路径，统一在新建/编辑用户内管理。分组页专属设置保留为按分组管理用户的入口。搜索输入不再触发弹层的外部关闭逻辑，并增加下拉标识；套餐无可选分组时明确提示需先配置套餐计费。

本地出口与远程代理共用编辑窗口的标题、协议、状态、滚动表单及底部操作布局，密码显隐与添加代理一致。本地直连协议只读，名称与状态可修改；它没有远程代理的主机、认证、有效期或到期回退，不把本机出口伪装成 HTTP/SOCKS 服务。
