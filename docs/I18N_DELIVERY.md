# 控制台 i18n 交付记录

日期：2026-10-21。源码基线：2b11f19895265db5bb5a124ee126775c6ce944db。

## 实现与清理

- 采用 i18next / react-i18next，29 个 namespace、4 种语言，共 116 份 JSON；每语言 4,787 个资源值，含复数形式与富文本模板。
- 覆盖模型、VM、设置、集群、日志、代理、风险、统计、账号和资金等前端模块及共享控件。支持英文、简体中文、台湾繁体中文、日文；日期数字与日历无障碍标签跟随界面语言。
- 删除旧的源文案查词典 messages.ts，移除 useLocale 的 t 接口及自动翻译任意传入字符串的 PageHeader 行为。页面使用语义键；用户内容、模型 ID、协议字段和原始诊断保持原值。
- 语言更新保持组件身份与表单草稿。沿用同一 tapmodels.locale 存储键，迁移已经发布的下划线 locale 值并写回 BCP 47；不迁移旧品牌数据，不更改 VM LANG/LC_ALL/TZ。
- 取消以翻译文本判断业务状态的路径，使用稳定状态码。修复日语开关标签折行、品牌上传原生控件语言不一致、命令菜单 Zustand snapshot 不稳定警告。
- coverage.test.ts 检查四语资源、复数、插值、富文本槽位、静态引用和可见硬编码。语言不变量按具体外部标识和原因记录；无法泛化的机器输出使用精确注释，不建立按目录忽略或历史问题基线。
