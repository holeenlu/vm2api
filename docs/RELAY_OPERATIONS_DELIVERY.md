# 中转站运营体系交付与本机验收

日期：2026-10-20。实施基线：1.3.199 / 819ee2a7c40b49fe81ebc3823e20373350a20545。目标仓库：holeenlu/vm2api，main。本文记录实际实现和实测边界，规划原文见 [RELAY_OPERATIONS.md](RELAY_OPERATIONS.md)。

## 已实现的运营闭环

站长创建资源和商业分组 → 创建客户、授权和充值或授予套餐 → 客户创建绑定分组的 API Key → VM / API 地址接受请求 → 按实际 usage 结算 → 站长查全站、客户查本人全部 Key 的记录及流水。

保留 tapmodels 的 Node 控制面、SQLite、React/TanStack 控制台与现有 Docker/KVM/账号执行机制；参考定制 sub2api 的业务关系和页面能力，没有修改相邻 sub2api 仓库。

| 角色 | 允许 | 不授予的能力 |
| --- | --- | --- |
| admin 站长 | 资源、商品价格、用户、授权、充值/扣款/冲正、订阅、全站记录和审计 | 不把平台诊断流量冒充客户消费 |
| super 运维 | VM/代理创建和维护、凭证写入、分组资源关联、调度、任务、运行监控与诊断摘要 | 用户财务、商品定价、Key 明文、凭证导出、原始请求正文、主机终端 |
| user 客户 | 获授权服务目录、自己的 Key、钱包、订阅、本人全部 Key 的使用记录/统计/导出 | VM、代理、集群及上游凭证管理 |

权限在后端路由、字段白名单、资源选择和查询范围同时执行；导航隐藏不是授权依据。面板会话不能代替协议 Key 调用推理接口。

## 资源与调度契约

- group_resources 使用稳定 vm.id，与凭证 account_uuid 解耦；空槽可分组，但不会因此获得凭证或可调度容量。
- VM 可属于多个分组；仍由同一个原调度器管理真实席位、并发、冷却与上游窗口，不为每个组复制容量。
- 分组反向编辑和 VM 编辑共用资源关系与版本。组内优先级保留原 VM 调度等级语义。
- VM 与 API 地址两种资源均接入商业授权；一个组只采用一种执行后端。API 地址支持 Anthropic、OpenAI Chat/Responses 路径。
- 新请求、排队选槽和重试重新读取 Key、授权、分组状态和成员。清空组、停用组、撤权不回落到全局资源。
- 客户会话粘性按用户、Key、计费组隔离；伪造同一个 session/device ID 不能复用另一客户的绑定。
- /v1/models 按获准分组与实际资源能力过滤。/v1/usage 对商业 Key 返回本人的商业权益，不暴露上游账号窗口。

## 资金、额度与用量

资金使用整数微美元。充值/扣款原因选填，必须带幂等键；余额、流水、Key 计量和结算摘要在 SQLite 事务中更新。重复结算不会重复扣款，普通用户资料更新不能覆盖余额。冲正追加相反金额的流水并引用原交易，不删除或篡改原账。

请求准入只检查当前余额/已消费额度，固定内存中的钱包归属和价格/倍率，不冻结资金或写入在途记录。请求完成后按上游对应链路的计量条件一次记账，保留套餐滚动窗口、幂等和流水；未计量的请求不占用余额。并发请求可能造成透支，后续请求由余额门禁阻止。

原资金预留、重启待用量恢复和人工对账机制已于 2026-10-30 按用户要求撤销。前向迁移 069 仅复制历史已完成消费到 billing_charges，不重扣历史款；旧预留记录保留为档案且不再参与运行。生产部署和历史档案物理删除需独立授权。


使用记录按请求发生时 user_id、api_key_id、Key 名称、计费分组快照归属；不根据当前 VM 属主或当前 Key 所有人猜测。客户 DTO 删除内部 VM/账号、供应商链、正文/凭证、内部价格来源；用户金额为实际扣费。充值不算请求消费，标准价不伪称采购成本/利润。未知金额保留未知状态。

IP 规则只使用可信连接 peer 地址；当前不信任客户端 X-Forwarded-For。若置于反向代理后，需要另行配置经过验证的代理信任契约；不要以伪造转发头测试或放宽白名单。

## 仍有边界的能力

- 规划第 4 节明确的首版故障策略为组内切换。显式跨组备用仍属后续方案，未启用、无永久旁路/废弃配置并存；套餐本身已实现。不能把 P5 的跨组备用也计为已交付。
- 独立 /v1/alpha/search 缺少可信单独用量契约，商业 Key 返回 commercial_search_unpriced；模型推理内自带搜索沿原 usage 计费。独立 count_tokens 入口随上游关闭并返回 404；API 后端仍走其能力边界。
- 排行最多汇总最近 5000 条匹配记录，超限页面明确提示缩小区间；不把部分汇总冒充全量。
- 售卖价格列表展示标准基础单价。长上下文、快速/优先模式使用原价格目录规则和请求快照结算。
- 线上支付、第三方退款、返利、跨项目双入口、生产数据演练和真实供应商验收未包含在本机模拟验收结果中。
