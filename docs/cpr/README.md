# CPR 学习研究与落地资料

本目录记录对本机 `codex-proxy-rs`（以下简称 CPR）的代码、接口、架构和发布资料的研究结果，并把值得 tapmodels（vm2api）吸收的方案整理成可执行的工程计划。

本目录同时记录研究、规划和已落地状态。P0-A/P0-B/P0-C 已在 2026-10-29 首版实现；实现状态以当前源码、迁移和测试为准，后续 P1/P2 仍以本目录路线和决策记录为准。

决策标签：

| 标签 | 含义 |
| --- | --- |
| 直接采用 | 方案与 tapmodels 目标一致，可在现有边界内落地 |
| 改造采用 | 设计有价值，但必须保留 VM、节点、供应商或商业运营语义 |
| 已有等效 | tapmodels 已有同等或更强能力，只吸收边界和验证方法 |
| 暂缓 | 价值明确，但当前没有足够需求或会扩大运行面 |
| 排除 | 与单槽隔离、集群、供应商运营或安全边界冲突 |

维护约定：

- CPR 或 tapmodels 的基线变化时，先更新 [证据索引](04-evidence-index.md)，再更新能力矩阵和路线
- 计划中引用的文件、字段和接口必须在实现前再次核对，不能把规划名称当成现有 API
- 真正实现后，将“计划”改为当前行为文档，并在对应交付记录中写验证结果和未覆盖范围
